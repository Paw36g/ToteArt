### DIRECTIVA DE IMPLEMENTACIÓN: SIMULACIÓN TEMPORAL DE ESTADOS DE PEDIDO

**REGLA DE CONSERVACIÓN:**
- Prohibido modificar estilos en `styles.css`, la autenticación, la conexión con Supabase o el flujo de favoritos.
- No alterar los botones de Servientrega ni el desglose de productos ya corregidos.
- Trabajar exclusivamente en la función que calcula y renderiza el estado dinámico del pedido en `pedidos.html`.

---

#### 1. LÓGICA DE TRANSICIÓN TEMPORAL DE ESTADOS (Tiempo transcurrido)
Para que los estados avancen de forma natural y automática según los minutos transcurridos desde que se creó el pedido (`fecha_pedido`), aplica la siguiente función de cálculo temporal:

**A) Si el método es ENVÍO A DOMICILIO:**
1. **0 a 2 minutos:** `PAGADO`
2. **2 a 4 minutos:** `EMPAQUETADO`
3. **4 a 6 minutos:** `ENVIADO`
4. **Más de 6 minutos:** `COMPLETO`

**B) Si el método es RETIRO EN LOCAL / TIENDA:**
1. **0 a 2 minutos:** `PAGADO`
2. **2 a 4 minutos:** `ESPERANDO TU LLEGADA`
3. **Más de 4 minutos:** `ENTREGADO`

---

#### 2. FUNCIÓN DE CÁLCULO DE ESTADO DINÁMICO EN `pedidos.html`

Inserta esta función auxiliar en el script de `pedidos.html`:

```javascript
function calcularEstadoDinamico(fechaCreacion, esDomicilio, estadoActualBd) {
  // Si en la base de datos ya se marcó manualmente como CANCELADO o RECHAZADO, respetarlo
  if (['CANCELADO', 'RECHAZADO'].includes(String(estadoActualBd).toUpperCase())) {
    return { texto: estadoActualBd.toUpperCase(), clase: 'status-cancelado' };
  }

  const ahora = Date.now();
  const fechaPedidoMs = new Date(fechaCreacion).getTime();
  const minutosTranscurridos = (ahora - fechaPedidoMs) / (1000 * 60);

  if (esDomicilio) {
    if (minutosTranscurridos < 2) {
      return { texto: 'PAGADO', clase: 'status-pagado' };
    } else if (minutosTranscurridos < 4) {
      return { texto: 'EMPAQUETADO', clase: 'status-empaquetado' };
    } else if (minutosTranscurridos < 6) {
      return { texto: 'ENVIADO', clase: 'status-enviado' };
    } else {
      return { texto: 'COMPLETO', clase: 'status-completo' };
    }
  } else {
    // Retiro en Local
    if (minutosTranscurridos < 2) {
      return { texto: 'PAGADO', clase: 'status-pagado' };
    } else if (minutosTranscurridos < 4) {
      return { texto: 'ESPERANDO TU LLEGADA', clase: 'status-esperando' };
    } else {
      return { texto: 'ENTREGADO', clase: 'status-entregado' };
    }
  }
}
