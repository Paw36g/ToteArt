2. PAGO: PROCESAMIENTO Y PASE DIRECTO AL RECIBO (checkout.html)
El usuario no debe esperar en pantallas intermedias una vez autorizada la transacción.

Modificar la simulación del pago para que:

Muestre únicamente el indicador de "Procesando pago..." mientras se validan y guardan los datos en segundo plano.

En cuanto el guardado concluya con éxito, cierre el indicador y despliegue el recibo de compra inmediatamente, sin pausas adicionales:

async function procesarPagoDirecto(guardarOrdenCallback) {
  const modal = document.getElementById('paymentSimulationModal');

3. PRELOADER: MOSTRAR SOLO AL INICIAR LA WEB O AL ACTUALIZAR (app.js)
El preloader no debe bloquear al usuario cuando hace clic entre enlaces de la tienda (Catálogo, Producto, Mis Pedidos, etc.). Solo debe ejecutarse cuando se entra por primera vez a la tienda o cuando el usuario presiona refrescar/actualizar la página (F5 o recargar).

Actualizar la lógica del preloader en app.js (o en el script donde esté inicializado):

(function gestionarPreloader() {
  const preloader = document.getElementById('toteartPreloader');
  if (!preloader) return;

  // Detectar si la página fue recargada manualmente por el usuario
  const navEntries = performance.getEntriesByType('navigation');
  const esRecarga = navEntries.length > 0 && navEntries[0].type === 'reload';
  
  // Detectar si es la primera apertura en la sesión actual
  const esPrimeraApertura = !sessionStorage.getItem('toteart_sitio_iniciado');

  if (esPrimeraApertura || esRecarga) {
    // Marcar como iniciado para la sesión
    sessionStorage.setItem('toteart_sitio_iniciado', 'true');

    // Desvanecer normalmente
    window.addEventListener('load', () => {
      setTimeout(() => {
        preloader.style.opacity = '0';
        setTimeout(() => {
          preloader.style.display = 'none';
        }, 300);
      }, 400);
    });
  } else {
    // Si es navegación entre pantallas internas, suprimir inmediatamente sin animación
    preloader.style.display = 'none';
  }
})();
